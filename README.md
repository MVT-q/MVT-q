## Featured Projects

### EducationPlatform

A desktop learning management system built with **WPF, C#, MVVM and Entity Framework Core**.

The project was developed as my college diploma project and took around three months to complete. It was one of my first large-scale applications and pushed me beyond my existing experience with desktop development, architecture and database-driven applications.

I worked through the implementation and studied the project's architecture and individual components in detail, allowing me to understand and explain how the major parts of the application work.

**Features include:**

- Authentication and authorization
- Multiple user roles
- Test creation and evaluation
- Learning materials
- User management
- Test result tracking
- MVVM-based architecture

[View repository →](https://github.com/MVT-q/EducationPlatform)

### Task Management App

A fullstack task management application built with **ASP.NET Core Web API and Angular**.

I developed the backend with ASP.NET Core and built the frontend with Angular, connecting both parts through a REST API. The project was mainly focused on practicing real-world frontend-backend communication and building a complete application.

**Features include:**

- JWT authentication
- Protected routes and API endpoints
- Project and task CRUD
- Project members
- Task assignment
- Search, filtering and sorting
- Server-side pagination
- Reactive frontend with RxJS

[View repository →](https://github.com/MVT-q/task-management-fullstack)
